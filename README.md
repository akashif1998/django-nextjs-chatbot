# 🤖 AI Chatbot | Django + Next.js

A full-stack AI chatbot project built with Django, Django REST Framework,
Next.js, LangChain, LangGraph, PostgreSQL, pgvector, Redis, and Celery.

## 📖 About This Project

This project is being used as a learning project to understand how to build
AI-powered web applications using Django and Next.js.

### What I Learned

- Django and Django REST Framework
- REST API development
- PostgreSQL and pgvector
- Redis and Celery
- LangChain and LangGraph
- RAG (Retrieval-Augmented Generation)
- Next.js and React
- Docker Compose
- Integration with OpenAI APIs
